# Семейное дело

Telegram Mini App для планирования контента в стиле кино 2000-х: темы, недельное расписание, автопостинг в Telegram-канал, напоминания и статистика.

## Что умеет

- **Темы.** Пишешь идею, Claude разворачивает её: угол подачи, хук, план и черновики под Telegram, Instagram, YouTube и TikTok. Идеи сохраняются в «Дела в работе».
- **Неделя.** Расписание с переключением недель. В каждый день можно добавить пост с текстом, временем, площадками и файлами. Claude может дописать текст.
- **Автопостинг в Telegram.** В назначенное время бот сам публикует пост в канал: текст, фото, видео или альбом.
- **Instagram, YouTube, TikTok.** Пока без API: в назначенное время бот присылает тебе в личку готовый текст и материалы с кнопкой «Выложил ✅».
- **Пейджер.** Утренняя сводка, напоминание перед постом, предупреждение о пустом завтрашнем дне и итоги недели в воскресенье.
- **Цифры.** Для Telegram-канала: подписчики, сколько пришло и ушло по дням, реакции, лучшие посты и советы Claude. Остальные площадки появятся после подключения их API.
- **Студия.** Поиск фото и видео на Pexels и прикрепление их к посту. Автомонтажа видео пока нет.

## Как устроено

```
Telegram ── бот (grammY) ──┐
Mini App (web/index.html) ─┼── Node.js + Express ── Postgres
                           ├── Claude API (темы, тексты, советы)
                           └── планировщик раз в 30 секунд: публикация, напоминания, сводки
```

Файлы, которые ты прикрепляешь, бот отправляет тебе в личку и хранит их `file_id`, поэтому отдельное хранилище файлов не нужно.

## Запуск на Railway

1. Создай бота в [@BotFather](https://t.me/BotFather) и сохрани токен.
2. На [railway.app](https://railway.app) создай проект: **Deploy from GitHub repo** → `semeinoe-delo`, затем **+ New → Database → PostgreSQL**.
3. В сервисе приложения открой **Variables** и добавь переменные из `.env.example`: `BOT_TOKEN`, `ANTHROPIC_API_KEY`, `ALLOWED_USER_IDS`, а в `DATABASE_URL` впиши `${{Postgres.DATABASE_URL}}`.
4. В **Settings → Networking** нажми **Generate Domain** и впиши этот адрес в `WEBAPP_URL`.
5. После деплоя напиши боту `/start` и добавь бота администратором в свой канал с правом публикации.

Секреты храни только в переменных хостинга. Репозиторий публичный, так что в код и в чат их не вставляй.

## Локально

```bash
cp .env.example .env   # заполни
npm install
npm run dev
npm test               # интеграционные тесты запускаются, если задан DATABASE_URL
```
